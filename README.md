# Awesome VPN — Telegram bot

Самостоятельный Telegram VPN-магазин на **aiogram 3** для Relax Dev. Бот создаёт и продлевает клиентов через **H1 Panel API**, выдаёт единую subscription URL и ссылки импорта в Happ / v2rayTun / INCI. Оплата — через Platega.

## Что уже реализовано

- Inline-меню: покупка, профиль, приложения, локации, приглашение.
- Тарифы из примера: 3 дня — 29 ₽; 30 дней — 139 ₽; 90 дней — 360 ₽; 365 дней — 1299 ₽.
- Автоматическое обнаружение именованных инбаундов на основной панели и связанных H1-узлах через read-only federation API.
- Одна покупка создаёт одну подписку со всеми распознанными локациями; один UUID добавляется на каждый узел сразу во все найденные на нём inbound IDs.
- Создание клиента, получение общей `subscription_url` / `sub_url`, отображение трафика и срока.
- Безопасное продление через PATCH с абсолютным `expires_at` (повтор запроса не прибавляет срок второй раз).
- Happ, v2rayTun и INCI import buttons формируются как `<subscription_url>/open/<app>`.
- Platega: создание платежей и автоматическая сверка статуса через `GET /transaction/{id}` каждые 20 секунд; ручная кнопка проверки остаётся доступной. Повторная обработка одного заказа сериализована.
- SQLite хранит пользователей и заказы.

## Важно до запуска

Для H1 API недостаточно только токена. Нужен **PANEL_API_URL** — базовый адрес панели из раздела «API-доступ», без завершающего `/api` (код сам добавляет `/api`). Токен панели передаётся как Bearer. Для бота, работающего за пределами РФ, документация H1 рекомендует адрес `direct-<node>.h1cloud.net:<port>`, если обычный адрес не отвечает.

Для Platega нужны **оба** значения:
- `PLATEGA_MERCHANT_ID` — UUID Merchant ID;
- `PLATEGA_SECRET` — API secret.

Merchant ID не заменяет Secret. Оба передаются только с сервера в заголовках `X-MerchantId` и `X-Secret`.

## Автоматическое обнаружение локаций H1

Если `PANEL_LOCATIONS_JSON` не задана, бот сам читает:
- `GET /api/inbounds` — инбаунды основной панели;
- `GET /api/fed/lagg` — список связанных серверов;
- `GET /api/fed/lproxy/{node_id}/inbounds` — инбаунды каждого связанного сервера.

Сопоставление выполняется по названиям/remark/tag инбаундов (Германия, Нидерланды, Польша, Финляндия, США, Япония, обход белых списков). Порты и ID не угадываются. Для ручного повторного сканирования администратор отправляет боту `/h1discover`; для подробного безопасного отчёта доступна `/h1diag`.

Покупатель выбирает только тариф. После оплаты бот создаёт одного клиента с одним UUID на каждом задействованном узле и прикрепляет его ко всем найденным на этом узле inbound IDs. H1 возвращает единую subscription URL; Happ/v2rayTun импортируют подписку целиком. «Автовыбор» остаётся функцией приложения, которая выбирает сервер из полученной подписки, а не отдельным inbound.

Если H1 возвращает нестандартные поля или названия инбаундов не содержат страны/назначения, запустите `/h1diag` и передайте администратору ответ, чтобы скорректировать сопоставление. Команда `/h1discover` выполняет только GET-запросы и не меняет настройки панели.

## Relax Dev

1. Создайте Python/Docker проект из этого репозитория.
2. Установите переменные окружения из `.env.example`. Не загружайте настоящий `.env` в GitHub.
3. В панели H1 откройте «API-доступ», скопируйте API URL и API token.
4. Оставьте `PANEL_LOCATIONS_JSON` пустой для автоматического обнаружения; после запуска администратор может выполнить `/h1discover`.
5. В Platega включите API-приём платежей. Callback URL настраивать не нужно: бот сам запрашивает статус платежей через API.
6. При необходимости задайте `PAYMENT_POLL_INTERVAL` (по умолчанию 20 секунд).
7. Запустите контейнер. Боту не нужен публичный домен или входящий HTTP-порт.

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Заполните .env настоящими значениями
python main.py
```

## Панель администратора

Администратор задаётся числовым Telegram ID в переменной `ADMIN_IDS` (несколько ID через запятую). После перезапуска доступна команда `/admin`.

Внутри панели:
- **Выдать подписку** — найти пользователя по Telegram ID или сохранённому @username, выбрать один из тарифов (3 дня / 1 / 3 / 12 месяцев); бот создаёт или продлевает одного H1-клиента с единым UUID на основной панели и всех обнаруженных федеративных узлах, затем отправляет пользователю ссылку.
- **Забрать подписку** — найти пользователя и подтвердить удаление его H1-клиента на основной панели и связанных узлах. Локальная запись очищается только после успешного ответа всех узлов.
- **Пользователи** — последние 15 пользователей и их состояние.
- **Платежи** — последние 15 заказов.
- **Статистика** — количество пользователей, пользователей с подпиской и сумма подтверждённых продаж.
- **Обновить локации H1** — повторное обнаружение инбаундов.

Поиск по @username работает для пользователей, которые уже запускали этого бота и поэтому присутствуют в его базе. Telegram Bot API не позволяет надёжно получить произвольный личный Telegram ID только по username. Если пользователь ещё не запускал бота, попросите его открыть `/start` и используйте его числовой ID. Для отмены ввода — `/cancel`.

Ручная выдача не создаёт платёж и не списывает баланс. Продление прибавляет выбранный срок к оставшемуся сроку (или к текущему времени, если подписка истекла). При ошибке на одном из узлов не повторяйте действие вслепую: сначала сверьте состояние клиента на всех узлах H1.

## Команды и кнопки

- `/start` — главное меню.
- `/h1discover` — администраторское read-only обнаружение стран и назначений по именам инбаундов; результат действует в памяти текущего процесса.
- `/h1diag` — подробная read-only диагностика связанных узлов и инбаундов H1; вывод скрывает UUID и секретные поля.
- «Купить VPN» — тариф → локация → платёж → автоматическая выдача доступа.
- «Мой VPN» — состояние, трафик, срок и кнопки импорта.
- «Перенести в приложение» — Happ / v2rayTun / INCI.

## Ограничения текущей версии

- Автообнаружение зависит от того, что названия инбаундов содержат распознаваемые названия стран/назначений. Неизвестные названия нужно сопоставить вручную через `PANEL_LOCATIONS_JSON`.
- Локации должны быть доступны через федерацию основной H1-панели. Частично завершённые операции при проблемах сети нужно сверить в панели перед повторным запуском.
- Ссылки `/open/happ`, `/open/v2raytun`, `/open/inci` предполагают, что ваша панель/домен поддерживает такие app-open маршруты, как в примере вашего конструктора. Это нужно проверить на тестовом клиенте.
- SQLite подходит для одного экземпляра бота с постоянным диском. Для нескольких реплик используйте общую PostgreSQL-очередь/хранилище и не запускайте два polling-процесса одновременно.
- Перед приёмом реальных оплат выполните тестовый платёж и убедитесь, что бот получает `CONFIRMED` через `GET /transaction/{id}`. Для автоматической сверки процесс бота должен работать постоянно.

## Безопасность

Никогда не помещайте `BOT_TOKEN`, `PANEL_API_TOKEN`, `PLATEGA_SECRET` в исходный код, скриншоты или GitHub. Все секреты задаются только в Secrets / Environment Variables Relax Dev.
