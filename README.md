# Awesome VPN — Telegram bot

Самостоятельный Telegram VPN-магазин на **aiogram 3** для Relax Dev. Бот создаёт и продлевает клиентов через **H1 Panel API**, выдаёт единую subscription URL и ссылки импорта в Happ / v2rayTun / INCI. Оплата — через Platega.

## Что уже реализовано

- Inline-меню: покупка, профиль, приложения, локации, приглашение.
- Тарифы из примера: 3 дня — 29 ₽; 30 дней — 139 ₽; 90 дней — 360 ₽; 365 дней — 1299 ₽.
- Выбор одной или всех настроенных локаций.
- Один UUID клиента на всех выбранных H1-узлах; каждый узел получает собственные локальные inbound IDs.
- Создание клиента, получение общей `subscription_url` / `sub_url`, отображение трафика и срока.
- Безопасное продление через PATCH с абсолютным `expires_at` (повтор запроса не прибавляет срок второй раз).
- Happ, v2rayTun и INCI import buttons формируются как `<subscription_url>/open/<app>`.
- Platega: создание платежа, callback с проверкой заголовков, дополнительная проверка статуса через API и защита от повторной активации.
- SQLite хранит пользователей, заказы и обработанные callback-и.

## Важно до запуска

Для H1 API недостаточно только токена. Нужен **PANEL_API_URL** — адрес API панели из раздела «API-доступ». Токен панели передаётся как Bearer. Для бота, работающего за пределами РФ, документация H1 рекомендует адрес `direct-<node>.h1cloud.net:<port>`, если обычный адрес не отвечает.

Для Platega нужны **оба** значения:
- `PLATEGA_MERCHANT_ID` — UUID Merchant ID;
- `PLATEGA_SECRET` — API secret.

Merchant ID не заменяет Secret. Оба передаются только с сервера в заголовках `X-MerchantId` и `X-Secret`.

## Настройка локаций H1

В `PANEL_LOCATIONS_JSON` задайте словарь локаций. Для каждой локации:
- `node_id` — ID подключённой панели из `GET /api/fed/lagg` (не ID инбаунда);
- `inbound_ids` — локальные inbound IDs именно этого узла из его `GET /api/inbounds`;
- `channels` — логические каналы. Для LTE/белых списков добавьте `bs`.

Пример:
```json
{
  "🇩🇪 Германия": {"node_id":"123","inbound_ids":["7"],"channels":["main","reality"]},
  "🌐 Обход белых списков": {"node_id":"456","inbound_ids":["2"],"channels":["main","reality","bs"]}
}
```

Узлы должны быть подключены к основной панели H1. Бот создаёт записи с одним UUID на выбранных узлах и затем получает объединённую подписку с основной панели. Не подставляйте inbound ID с другого сервера в текущий узел.

## Relax Dev

1. Создайте Python/Docker проект из этого репозитория.
2. Установите переменные окружения из `.env.example`. Не загружайте настоящий `.env` в GitHub.
3. В панели H1 откройте «API-доступ», скопируйте API URL и API token.
4. Заполните реальные `node_id` и `inbound_ids` для своих серверов.
5. В Platega включите API-приём платежей и укажите Callback URL: `https://ВАШ-ДОМЕН/platega/callback`.
6. Установите `PUBLIC_BASE_URL` равным публичному HTTPS-домену приложения.
7. Запустите контейнер. Проверка доступности: `GET /health`.

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Заполните .env настоящими значениями
python main.py
```

## Команды и кнопки

- `/start` — главное меню.
- «Купить VPN» — тариф → локация → платёж → автоматическая выдача доступа.
- «Мой VPN» — состояние, трафик, срок и кнопки импорта.
- «Перенести в приложение» — Happ / v2rayTun / INCI.

## Ограничения текущей версии

- Для каждого H1-узла требуется вручную получить и внести node ID и локальные inbound IDs; бот не угадывает структуру ваших серверов.
- Локации должны быть доступны через федерацию основной H1-панели. Частично завершённые операции при проблемах сети нужно сверить в панели перед повторным запуском.
- Ссылки `/open/happ`, `/open/v2raytun`, `/open/inci` предполагают, что ваша панель/домен поддерживает такие app-open маршруты, как в примере вашего конструктора. Это нужно проверить на тестовом клиенте.
- SQLite подходит для одного экземпляра бота с постоянным диском. Для нескольких реплик используйте общую PostgreSQL-очередь/хранилище и не запускайте два polling-процесса одновременно.
- Перед приёмом реальных оплат выполните тестовый платёж и проверьте callback Platega.

## Безопасность

Никогда не помещайте `BOT_TOKEN`, `PANEL_API_TOKEN`, `PLATEGA_SECRET` в исходный код, скриншоты или GitHub. Все секреты задаются только в Secrets / Environment Variables Relax Dev.
